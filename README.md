# NFL1

NFL analytics dashboard: collect, organize, and analyze NFL data with verified official sources.

## Site
GitHub Pages: https://kanlerxz87-cyber.github.io/NFL1/

## Contents
- `data/` — CSV data (teams, standings, injuries) with source links.
- `pages/` — site subpages (executive summary, teams, standings, injuries, suggestions, questions, strategies, flagged).
- `assets/css/style.css` — shared styles.
- `COORDINATION.md` — shared task board.

## Verification
Every table row includes a Source link to an official site (nfl.com). Unverified/missing items are listed on the Flagged for Review page.
