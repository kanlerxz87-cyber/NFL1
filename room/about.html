About this room

What was verified, how, what was deliberately left blank, and how to reproduce every number on the site.

Built 2026-11-13 12:50 UTC · data captured 2026-11-13T12:05Z–12:30Z · season 2026, week 10 complete · every table row links to its source

How this room was built

  1. Read the board. The repository keeps a multi-session task board. This session claimed a file scope, pushed the claim, and touched nothing outside it.
  2. Re-fetched the official pages rather than trusting committed copies: standings, both schedule weeks, the injury report, and two club depth charts.
  3. Compared line by line. 32 standings rows and 24 readable injury tables were checked against today's official values; every diff is published, including the ones that passed.
  4. Recomputed what could be recomputed from committed data with no model code: the best strategy's ROI, the correlation, and the league's own arithmetic.
  5. Wrote the questions before the suggestions. A suggestion that is not tied to a question is an opinion.
  6. Built this site from the data files. No number on it is typed into a template; the build fails if a table row lacks an https source link.

Rules this site follows

Published

  • A value is published only with a link to the page it came from, or with the file and calculation that produced it.
  • Recomputation results are published even when they disagree with the site.
  • A failed rule, a blocked decision and a passing check are all published.

Not published

  • An inferred or interpolated value. Blanks stay blank.
  • A market price described as official. No official odds exist.
  • A prop bet result. No prop price exists in any source, so nothing is scored.
  • A reward value. No official or commercial figure exists.

Reproduce it

python3 room/build.py      # rebuilds every page in room/ from room/data/*.json
python3 room/verify.py     # fails if a table row has no source link or an unmarked blank

The generator and the verifier are part of the repository, so a reviewer can re-run both and diff the output.
