What is deliberately not on this page

  • Closing lines and prices. nfl.com publishes no odds, so a market number cannot be labelled official. The own-lines page cites the hash-pinned feed it comes from.
  • Injury details beyond the official columns. Where the league page leaves injury or game status blank, this site leaves it blank.
  • Any projection for a game already played. The model is walk-forward; it does not re-score results it has seen.
