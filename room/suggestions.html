SG-01 Add a standings reconciliation gate that blocks a publish when a club's record disagrees with the official pageData currency · P1 P1
Why
The site currently serves NYG 5-2-1 and WAS 2-5-1 while the official page reads 5-3-1 and 3-5-1, because the Thursday game went final after the snapshot was taken.
How
Fetch the official standings page in the same run, parse 32 rows, compare W-L-T to the snapshot, fail on any difference unless the fetch itself failed (then mark the run official_unreachable and publish with a banner).
Cost
Low - one script, one workflow step
Risk
A fetch failure must not silently pass
Evidence

SG-02 Make the observed-price leaderboard the only headline tableStrategy leaderboard · P1 P1

Cost
Low - one renderer change
Risk
