Line Origination Strategies & Leaderboard

Goal: originate own NFL lines. Treat as a leaderboard competition with rewards for top-performing strategies. Covers single bets, parlays, and player prop bet combos.

Strategy Types

  • Single bet — one game outcome (spread/total/moneyline).
  • Parlay — multiple legs; must account for correlation between legs.
  • Player prop combo — combination of player props; correlation-aware.

Validation Gates (required to publish a strategy)

  1. Data source verified from official NFL.com (no inferred values).
  2. Out-of-sample backtest on at least one prior season.
  3. Minimum sample size (e.g., 100+ bets) before scoring.
  4. Statistical significance test (p < 0.05) vs. market baseline.
  5. Correlation values computed for all parlay/prop-combo legs.
  6. Luck removal: report variance, drawdown, and skill attribution.
  7. No manual input required for execution.

Correlation & Skill

Parlays and prop combos must report correlation values between legs to avoid hidden risk. Skill is isolated by removing luck: track variance, sample size, and significance. Strategies are selectively skill-based only after passing all gates.
