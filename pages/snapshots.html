What this page is: a ledger of the NFL's official injury report (nfl.com/injuries), read every six hours by a scheduled job. It exists so that a designation can be replayed as it stood at each read, and so that changes between reads (Questionable to Out, Did Not Participate to Limited to Full) are visible. Rows are copied from the page; blank cells stay blank. Method and retention rules: README · capture code · schedule. Limits: the raw page bytes are hashed, not kept; the terms-of-use review for keeping row-level copies is open (see Flagged for Review).

Every scheduled run appends a line here, including failed ones. "Changed? no" means the page was re-read and the parsed designations were identical to the last capture. The raw hash differs between requests because the page carries advertising and session markup; that is why the store also keeps a canonical hash of the parsed rows.
