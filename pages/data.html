What "verified" means here

Each value was read from an official NFL page and stored with that page's URL and a retrieval timestamp. The dataset is then re-checked by an automated gate that recomputes every team's record and points from the game-by-game scores and compares it to the official standings table. If a single score were wrong, at least one team's totals would stop matching.

Retrieval date: 2026-11-12 (UTC). Environment note: outbound HTTP from the build sandbox reaches only github.com, so all official NFL pages were read through the agent page-fetch channel; a bulk download (nflverse release) is blocked and is documented as such.
