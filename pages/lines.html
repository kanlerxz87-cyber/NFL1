How the number is built

Ridge-regularised opponent-adjusted points model, fitted on verified final scores:

home points = μ + offence[home] − defence[away] + HFA
away points = μ + offence[away] − defence[home]

Estimated from the captured season: home-field advantage -0.113 points (ridge penalty λ = 16.0, chosen by nested cross-validation inside the training window only).

The home-field estimate is close to zero because this season's verified results show home teams winning only 49.6% of decided games — see the correlation page before assuming a normal home edge.

Why no props or parlays are priced yet

Player-prop lines need per-player usage and yardage distributions. That requires an official player-statistics feed at row level, which was not obtainable here; inventing distributions from memory would break the no-hallucination rule. Parity with single bets also requires measured same-game correlations, which are published (see Validation & Correlation) so the dependency structure is ready — only the player-level inputs are missing.
