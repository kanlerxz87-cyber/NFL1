How to read this page

The availability table answers which listed starters are out. This table answers how far down the depth chart each club is projected to be once the official game designations are applied to the published depth chain: the first, second, third or fourth string at every tracked position, offence and defence. Three numbers are kept apart on purpose — the string that projects to play, the next certain string if the doubtful players sit, and the next man up if the projected starter cannot go.

Every row's Source cell carries two links: the club chart the chain was read from (an official page of the club itself) and the nfl.com injury report the designations were taken from. Neither is inferred; a string the chart does not list stays missing.

One chain per club chart line, ordered by the rank the club published. Club sites render a position as one or more lines (columns); each line stays separate and is labelled 'line N', never 'string', so a co-starter column is never implied to be a backup. The first four strings of each line are published; a string the chart does not list is absent, never invented. Official game designations from the injury report. 'Out' removes a player from the projected depth; Doubtful and Questionable still project to play, so they are counted as projecting and reported separately.

⚑ marks a name cell the scraper appears to have merged from two co-starters. It is published exactly as the club chart shows it and never split into two players; treat the chain behind it as unverified at that rank.

The next certain string excludes Doubtful/Questionable as well — that is the player who takes over if the projected starter cannot go. Chains stop at the fourth string the depth chart actually lists; nothing is invented beyond it. A club may render one position as several chart lines (columns) — those rows are labelled 'line N' and are chart layout, not depth order. The Source cell links the club chart the chain came from and the nfl.com report the designations came from.

Limits, stated plainly

  • A club that publishes no depth chart contributes no rows; it is counted in clubs_without_chart and never filled from another club.
  • A chart line may begin below the first string (the published list itself starts at rank 2); the row then says which ranks are not listed instead of inventing the missing ones.
  • 39 table-header rows the scraper captured as players (position 'POSITION', name 'NAME') were excluded from the register and counted here; they are a chart-rendering defect, not players.
  • 15 position rows hold a cell that looks like two co-starters merged by the scraper. They are published verbatim with a flagged marker and never split.
  • A depth chart is a listing, not a lineup; clubs promote players without notice, and the chart is a snapshot from the club site, not the league.
  • A position with no designation is not evidence that the player is healthy.
  • The string labels describe the depth chart, not the official lineup.
