How the rating is built

Walk-forward

Week w uses only the games completed before it. Ratings carry over from the previous season at 60%. Ridge penalties: rating 5.0, home field 5.0, scoring 8.0. These were fixed before any evaluation and are hashed: 48d2086663cbe0fd3ab9df08a0e4a5dc…

What it cannot see

Injuries, weather, quarterback changes and travel enter only through the score. There is no per-game inactive data in these sources, so the model cannot separate "worse team" from "team missing three starters".
