Rules this site enforces on itself

  • Every table row carries a link to the page or file the value came from; the build fails otherwise.
  • A value that cannot be confirmed renders as a labelled blank. It is never 0, "n/a" or a guess.
  • The bet log only contains bets whose price was observed in the source file.
  • Ratings never use the game they are predicting.
  • The rule set and its thresholds are hashed before scoring, so they cannot be tuned afterwards.
