Review workflow

  1. Read the decision questions and the flagged items.
  2. Compare the 20 suggestions and the three paths above.
  3. Select a path in the Review & Choose a Path box; file the prefilled issue to make the decision durable.
  4. Close the blocking questions, then — and only then — authorise implementation of individual suggestions.

The issue link points to the official repository issue tracker; it does not send data anywhere else.
