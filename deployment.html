Publishing configuration

Official GitHub documentation states that a Pages site published from a branch uses the root (/) or /docs folder of that branch and that index.html must be the entry file at the top level of the publishing source. This repository is configured for main / /. A .nojekyll file is committed so the plain generated HTML is published unchanged, and a GitHub Actions workflow runs the validator on every push and pull request.
