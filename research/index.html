What this section is not

It does not replace the other site generations in this repository — it adds to them. It is the only generation built on a sample large enough to test a strategy, because it is the only one whose research extract was committed as text the analysis could actually read. The duplication is recorded as flag U08.

Every number on this site was computed by a script you can run. Nothing was typed into a table by hand except the official values transcribed for verification, and those are stored with the page they verify.

Generated from data/s9cb/*.json by s9cb/site.py. Every table row links to the source it came from. A blank cell means the source does not publish that value; nothing is inferred to fill it.

Source data: nflverse (CC-BY-4.0), a parse of the NFL's own GSIS feed, the official weekly injury report and the official depth charts. Official entry points: schedules · standings · injuries · player stats.

Other site generations in this repository, all preserved: root dashboard · docs/ · verified-lab/ · referee/ · dashboard/ · lab/.

This is a research tool, not betting advice.
