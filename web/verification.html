What was verified, and against what

Every dataset used on this site is compared, cell by cell, with a hand transcription of the official page it claims to come from. The transcriptions live in data/evidence/ and carry the URL of the page each row was read from:

  • Standings — nfl.com/standings/league/2026/reg ↗ — 32 clubs, W/L/T/PF/PA.
  • Injuries — nfl.com/injuries/ ↗ — 279 player rows across 26 club sections.
  • Schedule — nfl.com/schedules/2026/REG10 ↗ — 14 games and 4 byes.
  • Depth charts — chiefs.com ↗, seahawks.com ↗ — because the league site returns 404 for depth charts (checked and recorded).

A FAIL means this site's own published data contradicts an official page and blocks publication. A FLAG means either another session's artifact disagrees with the official page, or an official page publishes nothing for a value the project would like to have. Flags do not block publication; they are listed below and on the Flagged for Review page, with the official link, so a person can arbitrate. No value is ever silently corrected.

How to reproduce this yourself

python3 tools/evidence_from_official.py   # write the official transcriptions
python3 tools/verify_official.py          # compare every repo dataset, cell by cell
python3 tools/build_decision_room.py      # recompute the verdicts
python3 tools/build_dashboard.py          # render these pages
python3 tools/verify_dashboard.py         # independently recompute every published figure

The transcription step is manual by design: an audit is only worth something if the person checking the data read the page. The comparison and every arithmetic check are automated and run on every push.
