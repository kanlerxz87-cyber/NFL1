How to read this page

A decision is only reasonable when the information behind it exists. This page sorts every open question into four buckets, in the order you should work through them:

  1. Needs only a choice — the evidence is already in the repository. Reading the row and picking an option is the whole task.
  2. Blocked on information — a named fact is missing, and the row says exactly which official page or feed would supply it.
  3. Contradictions — an official page and this repository disagree. These are on the Flagged for Review page with both links.
  4. Not yet meaningful — questions that look urgent but cannot change any decision until an earlier item is settled.

The one question that gates everything else

Every strategy, leaderboard, reward and 'edge' number depends on a price that could actually have been taken. This repository contains no book-level odds: the market numbers are consensus closing numbers from the nflverse mirror, as the Verification page states and the model itself measures. Until a licensed odds feed is connected, the honest answer to "what is this bet worth?" is blank and it is published as a flag rather than filled in.

See NFL.com ↗ for the league's own game information, and the flag register for the exact fields that stay blank.
