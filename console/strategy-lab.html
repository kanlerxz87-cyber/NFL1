Strategy lab

Own lines, the board, the gates, correlations with n, and how luck is removed.

Every figure on this page comes from data/s9cb/leaderboard.json, data/s9cb/correlations.json and the hash-pinned feed behind them. Rules were fixed before evaluation, 12 rules were tested, and the p-values are adjusted for that.

Nothing here is a recommendation. Every number is retrospective. No strategy has a prospective sample, and the brief forbids ranking on realised return. A rule that clears all eight gates is a candidate for a prospective run, not a licence to stake.

The eight gates

GateWhat it requiresWhy
G1walk-forward / pre-game information onlyEvery input to the bet decision is known before kick-off and, for the model rules, comes from a fit that used only earlier games.
G2observed prices on every scored betEvery scored bet carries a price taken from the source file. No -110 assumption is used.
G3at least 200 scored betsBelow this, a run of luck is indistinguishable from skill at any plausible effect size.
G4hit rate beats the break-even implied by the actual prices takenBreak-even is computed from the real price on each bet, not from 0.5.
G5survives multiple testing (BH-adjusted p < 0.05, 12 rules tested)Testing many rules and reporting only the best one manufactures winners; the Benjamini-Hochberg step charges for that.
G6positive in a untouched holdout (2024 + 2025)The holdout seasons were never used to tune the rule thresholds.
G7positive in at least 60% of individual seasonsAn edge that exists in only one season is a season, not a strategy.
G895% bootstrap confidence interval on ROI excludes zeroTen thousand resamples of the actual bet log; the interval must sit above zero.

Rows in this table carry no source link because: methodology, not data: a gate is a rule we wrote, not a value an official page publishes.

Removing luck

  • Benchmark, not zero. A rule is compared with the break-even implied by the prices it actually took, not with 0.5.
  • Multiplicity. 12 rules were tested; the reported p-value is Benjamini-Hochberg adjusted.
  • Resampling. Ten thousand resamples of the actual bet log produce the ROI interval.
  • Holdout. 2024 and 2025 were never used to tune thresholds and are scored separately.
  • Still missing. A game-cluster adjustment. Bets inside the same game are not independent, so the per-bet interval is too narrow. See S11.

Where the data comes from

nflverse publishes parsed copies of the NFL's GSIS feed, the official weekly injury report and the official depth charts. nfl.com is the primary publisher but blocks automated clients, so nfl.com pages are cited as the official entry point and spot-checked separately against this repository's hand transcriptions. Every row on this site links to the official page it was read from. A value no official page publishes is printed as a labelled blank, never inferred. Built by console/build.py; checked by console/verify.py. Research tool, not betting advice.
