How to read this table

The third column is evidence. The fourth is the absence of evidence. A decision taken from the third column alone is a decision taken from half the picture: it looks the same whether the missing half would have confirmed it or refuted it. Where the answer is unanswered, no page in this repository and no official page this session read settles it, and the value is not filled in.

Every row on this site links to the official page it was read from. A value no official page publishes is printed as a labelled blank, never inferred. Built by console/build.py; checked by console/verify.py. Research tool, not betting advice.
