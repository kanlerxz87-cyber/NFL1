Rules this page holds itself to

  • No value is inferred, interpolated or filled in. An unknown value renders as a labelled blank.
  • Every table row carries the URL of the official page the value was read from, or is marked unverified.
  • Where the repository's own file disagrees with the official page, both are printed and the disagreement is flagged; neither is silently corrected.
  • Historical data is a parsed copy of the league's feed, not the league's own page. It is labelled as such, pinned by sha256, and independently reconciled against the official table.

Every row on this site links to the official page it was read from. A value no official page publishes is printed as a labelled blank, never inferred. Built by console/build.py; checked by console/verify.py. Research tool, not betting advice.
