Why a diff and not a snapshot

A snapshot is written only when the state changes. The backtest sample grows only when a new game completes, so two builds minutes apart usually show zeros — which is the honest diff, not a missing one.

Snapshots on disk: 1 · current 20261115T131729Z.json · previous none. There is only one snapshot so far, so every change column is blank rather than zero: a change cannot be computed against nothing.
