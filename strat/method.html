What is measured, and with what

Every number on this site comes from one of three places: an official nfl.com page fetched during a session, a third-party extract of the NFL's own statistics feed (labelled as such), or a computation over those two whose script is in this repository and whose output is a JSON file.

Reproduce every number

cd s9cb/analysis
python3 run.py                 # rebuilds the extract-derived research JSON
python3 ../../strat/proper_score.py    # Brier skill, intervals, multiplicity
python3 ../../strat/dual_total.py      # the two estimators and the verdict
cd ../.. && python3 strat/preregister.py && python3 strat/demotion.py \
  && python3 strat/what_would_change.py && python3 strat/registers.py \
  && python3 strat/build.py && python3 strat/verify.py

The reproduce steps are the ones this build ran. strat/verify.py fails on a broken link, a table row with no source, a placeholder in a cell, or a page that nothing links to.

What is deliberately blank

  • Prop, prop-combo and same-game-parlay scores: no price exists.
  • Opening prices: no opening-price source exists.
  • Live bets and demotions: nothing is live.
  • Estimator B for a fixture where neither team has played this season.
  • Any correlation or interval whose sample floor is not met.
