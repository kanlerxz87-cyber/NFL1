What this is

A verified-data-first research system for the NFL. It collects official league data, checks it line by line, computes only what the data supports, and refuses to publish anything it cannot source. It is built to originate betting lines and to rank candidate strategies on a leaderboard - and today it correctly reports that it cannot yet do either, because the two datasets an edge is measured against are not obtainable from this environment.

Nothing on this site is a betting recommendation, and no value has been estimated to fill a gap.

The single most important result

Thirty-eight correlation tests were run across 21 signals with Benjamini-Hochberg false-discovery-rate control. At p<0.05 alone, 1.9 false positives would be expected by chance. Nine tests survive FDR control at α=0.1 and all nine are definitional - win percentage against other expressions of the same game outcomes. Zero non-mechanical findings survive. Any availability or injury signal that appears to work in this dataset is, so far, indistinguishable from a tautology or from noise.
