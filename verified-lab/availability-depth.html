Depth charts are unavailable. NFL.com does not publish a public weekly depth chart. The league's official weekly depth-chart feed is Sportradar's NFL Official API (Sportradar is the NFL's official data partner) and it requires an API key that this environment does not hold. Individual club sites publish charts in inconsistent, unversioned formats.

Consequence: String level (1st/2nd/3rd/4th) cannot be attached to any player row. The availability index below is therefore computed WITHOUT string weighting and is labelled MODELED.

Deficiency tracking by unit

Offensive and defensive did-not-practise counts are tracked separately because the brief asks specifically about defensive deficiencies. The league totals this week are 135 offensive entries against 114 defensive entries, with 43 defensive DNPs and 49 offensive DNPs. What cannot be established is which string each absence promotes, so a starter and a fourth-string rotational player contribute identically to the pressure index. That is the single largest weakness in the availability model and it is stated rather than hidden.
