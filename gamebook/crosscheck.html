Two sources, one fact

The weekly inactives article and the game's own Game Book print the same list; both are captured, and every disagreement is published instead of resolved by preference.

Same fact, two official documents

The league publishes a club's game-day inactives twice: in the dated weekly inactives article, and in that game's own Game Book, on the Not Active line. The two are captured independently and compared here name by name. A row where they disagree is not averaged and not adjudicated in code - it is published with both values and sent to the review page.

No comparison yet: a comparison needs both sources captured for the same club-game. The article side is in the repository now (Week 10, 147 names, 24 clubs: the official article); the Game Book side arrives with the Actions sweep. One of its own pages, e.g. the Patriots-Lions game centre, links the Game Book for that game. This table stays empty rather than being filled with a claim.

What this proves

  • It is a check on the parser, not on the league. If the PDF reader loses a name, this table shows one fewer than the article, and the gate fails the build.
  • It is a check on timing. The article is published before kickoff and the Game Book after it; a club that changed its declared inactives between the two would show up as a one-sided name, which is a data event worth recording, not noise to smooth away.
