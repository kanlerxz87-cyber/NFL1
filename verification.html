Automated checks

tools/verify.py

The validator parses every generated HTML page and enforces:

  • every <tr> in a table.data-table contains at least one anchor to an allow-listed official domain;
  • rows marked data-verified="false" link to flagged.html and keep all data-value cells empty;
  • every internal href and src resolves to a file in the repository;
  • every source id used by a table row exists in data/sources.json and points to an allow-listed official domain.

Results are printed by the script and are also run in GitHub Actions on every push and pull request. The live site is checked after the merge.
