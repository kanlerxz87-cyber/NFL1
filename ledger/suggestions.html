Recommended: A, then C. The most valuable thing in this repository is not a strategy — it is the demonstration, with controls and a pre-registration, that a reasonable own-line model does not beat the close. That result is worth publishing cleanly. Path B is worth doing only if someone intends to keep originating, and the honest expectation from this evidence is that it will produce the same answer with more decimal places.
