## Procedure

| ID | Step | Action | Detail | Official source | Verified |
| --- | --- | --- | --- | --- | --- |
| VP-01 | 1 | Transcribe, do not paraphrase values | Each official page was fetched and read; values copied cell by cell into data/*.json | [S02](https://www.nfl.com/standings/league/2026/REG) | yes |
| VP-02 | 2 | Attach an official source to every row | The generator appends a source link and a verification badge to every table row | [S22](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) | yes |
| VP-03 | 3 | Leave blanks blank | Empty strings render as empty cells; no substitution, interpolation or estimation | [S02](https://www.nfl.com/standings/league/2026/REG) | yes |
| VP-04 | 4 | Flag unverified project assertions | Rows with verified=false link to Flagged for Review and keep all value cells blank | [S24](https://github.com/kanlerxz87-cyber/NFL1) | yes |
| VP-05 | 5 | Automated validation | tools/verify.py checks source domains, unverified blanks, internal links and generated-file integrity | [S22](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site) | yes |
| VP-06 | 6 | Recompute derived values | tools/compute_correlations.py recomputes correlations from the committed official standings | [S17](https://www.itl.nist.gov/div898/handbook/glossary.htm) | yes |
| VP-07 | 7 | Build and link check before merge | HTML pages generated, internal links resolved, then Pages confirmed live | [S23](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site) | yes |

Automated enforcement: `tools/verify.py`; derived values: `tools/compute_correlations.py`.
