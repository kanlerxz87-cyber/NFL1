S1 · Pythagorean regression (fade the lucky) · single

Skill basis: Point differential is the skill component of a record; the gap to actual wins is the luck component. This is the most direct available implementation of 'remove luck'.

How luck is removed: The signal IS a luck estimate, so the strategy must also pass the placebo test: shuffled pyth_delta must produce no edge.

Gate status: G1 G2 G3 G4 G5 G6 G7 G8 G9

S2 · Confirmed QB disruption · single

Skill basis: QB is the highest-leverage position in the sport; a verified starter change is a discrete, timestampable, non-random event.

How luck is removed: Permutation test on QB-change games only; edge must survive leave-one-team-out so it is not one franchise's season.

Verified instances in Week 10: CLE (Watson to start); AZ (Beck to start); MIA (Willis to IR, McCord in line); SEA (Darnold ruled out, Lock to start)

Gate status: G1 G2 G3 G4 G5 G6 G7 G8 G9

S3 · Defensive absence cluster · single

Skill basis: Deficiency tracking is mechanical and available before kickoff.

How luck is removed: Baseline-relative z-score, then bootstrap CI across weeks.

Gate status: G1 G2 G3 G4 G5 G6 G7 G8 G9

S4 · Streak fade (public-bias contrarian) · single

Skill basis: A behavioural bias, not a performance signal - the most durable class of edge because it does not decay with data.

How luck is removed: Must hold separately in each of the last three seasons; a one-season result is indistinguishable from noise.

Gate status: G1 G2 G3 G4 G5 G6 G7 G8 G9

P1 · Same-game script: favourite + under · parlay

Skill basis: Correlation is the ONLY legitimate source of parlay edge; a parlay of independent legs always inherits the multiplied vig.

How luck is removed: Joint probability must be recomputed with the MEASURED rho (odds.parlay_fair_prob), never the independent product.
