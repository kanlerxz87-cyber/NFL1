Method & flags

Capture protocol

  • One read of each official game-centre page and one read of each official Game Book PDF (static.www.nfl.com) during session d9e28eb2-nfl1; chunk 0 of every PDF carries the full game summary (lineups, substitutions, Did Not Play, Not Active, officials, weather, scoring, attendance).
  • Captures are transcribed to data/gamebooks/raw/ — CAP-06 transcription-of-fetch-text, disclosed on every page. data/gamebooks/manifest.json pins each file with sha256; data/gamebooks/source.json carries the game-centre and PDF URLs per game.
  • Blanks are empty-as-extracted. A field whose label did not survive the extraction is null in data/gamebooks/parsed.json and flagged here — it is never reconstructed from context, other sources, or inference.
  • The official league inactives page (nfl.com/inactives) published nothing for the 2026 season at capture time, so these Game Books are the only official game-day inactive source in the repository.
