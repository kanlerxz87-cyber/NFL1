Why this is the honest test

Luck is removed by changing the question from "did this rule make money?" to "would a random set of the same number of bets, chosen from the same weeks, have done as well?". Ten thousand random draws, fixed seed, published p-value. A rule that cannot beat that distribution has not demonstrated selection skill, however good its raw record looks.

Limit, stated plainly: This measures whether the SELECTION has information. It does not measure profit, because no book prices exist. With no book prices, profit cannot be computed, so what is measured is whether the rule's selection carries information about the margin relative to my own line.
