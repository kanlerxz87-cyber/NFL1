How the tables on this site are held to the rule

RuleHow it is enforced
Every data row carries an official source linkThe generator renders a Source column on every table that shows data; the build fails if a row is emitted without one.
Unconfirmed values are blank, never inferredA missing value renders as a labelled blank cell, not as a zero or an estimate.
Ratings never see the futureRatings for week W are fitted only on games with week < W, in every backtest fold.
Rules are fixed before outcomesThe rule definitions live in one file whose SHA-256 is published on the Lines and Strategy pages.
Multiple testing is correctedBenjamini-Hochberg at FDR 0.10 across every graded rule.
Luck is tested, not assumed awayTen thousand same-size random draws from the same weeks, fixed seed, published p-value.
