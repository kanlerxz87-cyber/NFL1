Rules this site is built under

  1. No value is inferred, interpolated or filled. A blank on the source page is published as "not published"; a value nobody fetched is "not read"; a value no official page confirms is "unverified" and is not shown as a number at all.
  2. One source per row. Every table row links the official page it was checked against. The build fails if a row in a table with a Source column lacks a link.
  3. A transcription is verbatim. Jersey numbers, mismatched club codes, blank cells and multi-name slots are preserved in the raw field rather than cleaned away.
  4. A comparison is a comparison. Where the repository's own file disagrees with today's page, both numbers are shown and neither is edited — those files belong to other generators.
  5. Numbers are computed, not typed. Every figure on these pages is derived by tools/desk/build_site.py from data/desk/*.json, and tools/desk/verify_site.py re-reads the rendered HTML and recomputes it independently.
  6. A finding can be retired. A claim from the brief that no longer matches the live page is recorded as resolved with the reading that retired it, not quietly dropped.

How the pages are built

tools/desk/emit_data.py reads the session's transcriptions and the named repository files and writes data/desk/*.json. tools/desk/build_site.py renders those JSON files into the pages you are reading. tools/desk/verify_site.py fails if a page in desk/ would change on rebuild, if any local link is broken, if a Source cell lacks a link, if a table is empty, or if a number on a page cannot be reproduced from the data layer.

What this site is not

It is not a betting recommendation, and it does not publish a pick. It publishes probabilities, their uncertainty, and the evidence behind them — and where the evidence runs out, it says so. No official NFL odds exist; market columns come from a third-party price file and are labelled as such wherever they appear.
